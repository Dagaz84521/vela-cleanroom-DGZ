# Time Tracker 时间记录

从组件列表的「专注」分类添加「时间记录」。小窗的「今日记录」按每小时六格展示全天，色块区域独立支持鼠标滚轮滚动；单击看详情，双击已记录色块修改类别和备注，双击已结束的空白色块补记。未结束的时间块不能记录，夏令时重复小时会显示 UTC 偏移。

「快速记录」在同一小窗内切换到记录页，选择类别、填写可选备注后「确认记录」；「延续上一活动」可以一键保存，沿用该时间段之前最近记录的类别和备注。快速记录默认跳过已有记录。双击编辑页的「保存修改」明确只覆盖选中的一个时间块；编辑页的「延续上一活动」仅填入已加载的上一条活动，仍需保存才写入。批量补记和覆盖继续通过「每日时间轴」完成。

保存成功回到概览并刷新颜色；写入失败保留记录页和草稿。返回或按 Esc 不写入，保留最近八个时段的临时草稿和概览滚动位置。草稿仅在本次小组件挂载期间保留，历史记录仍持久化至 SQLite。默认尺寸为 340×470，最小尺寸 280×450；已有过小的时间记录小窗通过原有实例更新机制调整到最小尺寸。

「定位当前」按点击时的真实时间选中当前 10 分钟时间块，并滚动到区域中央；日初、日末按可滚动边界截断。原实现将不同 offsetParent 下的 offsetTop 相减，导致偏移或滚回顶部。现使用相同参照的矩形位置计算，并处理画布缩放、滚动容器边框及跨午夜日期刷新；跨日加载数据库导致色块区重挂载时也会保留定位意图，共享时钟后续更新不会打断手动浏览。定位修复新增 9 项回归测试，Time Tracker 合计 52 项前端测试通过，另有 18 项实际 Edge 浏览器检查覆盖缩放、滚动、窗口尺寸、切页、时间边界和跨午夜。

「每日时间轴」打开详情；设置窗口也有独立的「时间记录」入口，即使删除所有时间记录小组件，仍可查看历史、补记和关闭提醒。点击时间块可多选，Shift 点击选择连续范围。单个已有时间块可以修改；批量操作默认跳过已有记录，覆盖需要确认。自定义类别删除采用归档，历史引用仍保留。

## 调度

- 默认开启，活跃时间为本地 07:00–23:00，每 10 分钟提醒。可选 10、20、30、40、50、60 分钟；记录粒度始终为 10 分钟。
- 提醒从每日活跃开始时间计算。例如 07:00 开始、50 分钟间隔：07:50、08:40、09:30。结束边界还有一个不足完整间隔的尾段提醒。结束时间早于开始时间表示跨午夜，开始/结束必须不同且对齐整 10 分钟。
- Rust 在应用 setup 时启动唯一工作线程，复用设置镜像的 Condvar 唤醒机制；下一次唤醒根据真实时间戳计算，最多每 30 秒重新检查系统时间。调度与 React、小组件实例、显示器及桌面视图无关。
- SQLite 保存提醒游标，通知先领取游标再发送。重启不追发历史；超过 90 秒的运行间断和时间倒退不追发，短暂延迟只处理最近到期的一次。系统恢复后按新的当前时间继续。漏记始终是空白，用户可手动补记。
- 复用现有通知中心、WinRT Toast 和勿扰/专注设置。点击 Toast 打开设置页，并保留该条通知原始时间段；旧通知点击不会推进或回退调度游标。

## 持久化与状态

迁移 v12 新增 `time_categories`、`time_blocks`。每条记录是实际经过的 600000 毫秒，`start_ms` 唯一；同时保留本地日期和当时 UTC 偏移，以及类别、备注和创建/修改时间。不存在占位活动记录，也不会推断漏记。

Repository 校验类别、已结束的整 10 分钟时间块和备注长度，批量写入在单一事务中完成。默认冲突跳过，显式覆盖保留记录 ID 和创建时间。错误会回滚整批。配置与提醒游标复用现有 SQLite settings 表。

UI → Zustand → Persistence Port → Tauri IPC → Repository → SQLite。IPC 使用可信窗口门控和 ts-rs 生成类型。UI 在数据库提交后才刷新；`sync:time-tracker` 通过已有 Tauri 事件 hook 通知各窗口重新读取，过期读取不能覆盖新提交。最多缓存七个日期。

每日边界使用本地日历，循环使用真实时间戳，因此夏令时当天可能为 138 或 150 个时间块。重复小时展示 UTC 偏移。连续活动摘要只合并显示，原始记录不被重写。

## 验证与范围

纯函数测试覆盖六种间隔、非整点启动、跨日/边界/夏令时；Rust 测试覆盖休眠恢复、重复领取、间隔修改、SQLite 去重/修改/事务失败/重启、类别归档和旧通知时间段。前端测试覆盖时间轴选择、编辑确认、批量补记、延续、设置与失败后保留草稿。

真实 Windows Toast 点击、系统休眠和多显示器交互还需桌面手工验收。当前时间记录通过 SQLite 持久化；现有 JSON 备份格式尚未包含这两张新表。没有账号、云同步或自动识别。
